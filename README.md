# Customer Data Preprocessing with Python

A Python project examining how customer records can be extracted, cleaned, structured and visualised.

## Project questions

- What customer fields are available and how are they represented?
- Are there missing, duplicate or inconsistent entries?
- How can cleaning decisions be checked before analysis?

## Tools and methods

- Python
- pandas
- dictionaries and lists
- JSON
- functions
- seaborn
